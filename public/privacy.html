Tu progreso y tus datos

Gravity Shift guarda monedas, personajes, ajustes, hazañas y récords diarios en el almacenamiento local de este dispositivo. Puedes exportar, importar o borrar el progreso desde Ajustes.

Informes de prueba

Los tiempos de fotograma y datos de partida se calculan localmente para ajustar la calidad. El historial de pruebas solo se conserva entre sesiones si activas esa opción. No se envían informes ni analítica a un servidor. Puedes descargar un informe y compartirlo voluntariamente.

Instalación sin conexión

La web guarda una copia de sus recursos para poder funcionar sin conexión después de completar la primera descarga. El navegador puede eliminar esa caché para recuperar espacio. Las actualizaciones se aplican cuando aceptas recargar o vuelves a abrir el juego.

Anuncios

La web no carga anuncios. La compilación móvil permite activar voluntariamente anuncios de prueba de Google AdMob. Antes de solicitar anuncios comprueba el consentimiento mediante el SDK de Google; puedes revisar las opciones de privacidad desde Ajustes. No hay anuncios comerciales activos ni ingresos en esta versión. Los anuncios y servicios de las tiendas necesitan conexión.
